# GRIT — 인터랙션 작업 노트

## 프로젝트

GRIT은 CMF 실험 스튜디오다. 클라이밍 홀드를 실루엣 고정 변수로 두고 재료만 바꿔가며
기록한다. 스포츠 용품 브랜드가 아니다. 실패한 표본도 아카이브 내용이다.

재료 축: 마찰(압축 초크 + CMC) / 결(패브릭) / 수분·저항(실리콘) / 자기력(SPECULATIVE)

## 파일

`exhibition/grit-wall.html` — 단일 파일. 원격 자산은 손 추적 wasm과 모델 둘뿐.

`file://`로는 안 된다. 웹캠이 보안 컨텍스트를 요구한다 — Firefox는 거부하고
Chrome은 실행할 때마다 권한을 다시 묻는다. `?mouse`를 붙이면 카메라를
건너뛰고 포인터로 돌아간다.

작업 중에는 GitHub Pages로 본다:
`https://hysy0299-gif.github.io/cre8-26-2/exhibition/grit-wall.html`
`side` 브랜치 루트를 그대로 서빙한다. push하면 30초쯤 뒤 반영.

WebGL2 프래그먼트 셰이더 하나 + 풀스크린 삼각형. 형태는 전부 레이마칭으로 나온다.
이미지 텍스처는 이전 버전에 있었으나 제거됨.

## 컬러

deck spec. 이 네 개 외에는 쓰지 않는다.

```
GRIT WHITE  #F5F5F5
GRIT BLACK  #010101
GRIT MID    #AEB6BF
GRIT GREEN  #CBD7D4
```

셰이더는 밀도를 종이에 감산으로 올린다. 발광하지 않는다.
램프: `WHITE → GREEN → MID → BLACK`

MID는 흰 배경 10px 텍스트에서 대비 1.8:1이라 못 읽는다. 작은 글자에는 쓰지 말 것.
BLACK을 불투명도로 눌러 쓴다(`.55` / `.32`).

## UI 금지 사항

`border-radius` 없음. `box-shadow` 없음. Inter 없음. 그라디언트 없음.
중앙 정렬 3열 카드 그리드 없음. 여백은 비대칭(좌 68px / 우 38px).

## 셰이더 파라미터

| 이름 | 현재값 | 역할 |
|---|---|---|
| `FOV` | `2.10` | 시야각. 높을수록 덩어리가 프레임에서 작아짐. 2.5 넘으면 가장자리 왜곡 |
| `radius` | `6.6 → 2.8` | 셸 반경. 흩어짐 → 뭉침. **수축이 보이게 하는 핵심값** |
| `fold` | `1.62 → 0.18` | 접힘 진폭. 1.0 초과면 형태가 조각남. 남은 값이 표면 요철 |
| `h` | `smoothstep(0.02,0.98,uHold)` | 뭉침 진행도 |
| `p.y` | `×1.12` | 뭉칠 때 세로 압축 → 가로로 넓게 |
| `p.z` | `×1.22` | 깊이 압축 → 부조처럼 |
| 노출 | `1.32 → 2.10` | 위는 성글게, 아래는 꽉 찬 면 |
| 시간 감속 | `1 - 0.93 * hold` | 뭉칠수록 요동이 잦아듦 |

레이마칭 100스텝. `fold`를 2.0 이상 올리면 표면을 못 따라가 노이즈가 낀다.

## 입력 — 손 랜드마크

MediaPipe HandLandmarker. 손 하나당 관절 21개, 최대 두 손, 좌우 라벨까지 나온다.

한때 라이브러리 없이 프레임 차분으로 갔었다. 그건 움직이는 덩어리의 중심점과
총량까지만 준다 — 주먹과 편 손을 구분 못 하고, 손가락이라는 개념이 없고,
두 손을 못 가른다. 커스터마이징을 몸짓으로 받으려면 못 쓴다. 걷어냈다.

**모든 판정이 손 자체 크기 대비 비율이다.** 단위는 손목(0)에서 중지 관절(9)까지의
길이 — 손가락이 뭘 하든 거의 안 변하는 유일한 길이다. 그래서 카메라에
가까이 가든 멀어지든 주먹 판정이 흔들리지 않는다. 근접 밴드가 필요 없어졌다.

| 값 | 재는 것 | 쓰는 곳 |
|---|---|---|
| `grip` | 오른손. 손끝 4개 → 손목 평균거리 | 뭉침 |
| `pinch` | 왼손. 엄지끝(4) → 검지끝(8) | 크기 |
| `x, y` | 오른손 중지 관절. 미러링됨 | 회전, 앵커 |
| `energy` | 그 손의 이동 속도 | 내부 접힘 요동 |

임계: `GRIP_OPEN 2.30` / `GRIP_SHUT 1.20`, `PINCH_SHUT 0.30` / `PINCH_OPEN 1.40`.
전부 손 너비 단위. `D` 오버레이에 실측값이 뜨니 그거 보고 맞춘다.

좌우 라벨은 미러링된 이미지 기준으로 돌아온다. 방에서 반대로 잡히면
`HAND_FLIP`만 뒤집는다.

원격 자산 두 개를 받는다 — jsdelivr의 wasm과 Google의 `.task` 모델.
전시장에 인터넷이 없으면 `exhibition/vendor/`로 내려서 경로만 바꾼다.
그 둘 말고 받아오는 건 없다.

## 인터랙션

버튼이 없다. 주먹이 버튼이다.
뭉침 약 1초, 손을 펴면 흩어짐 0.6초. 이징 `Math.pow(S.down > S.hold ? 0.07 : 0.004, sec)`

`grip`이 0/1이 아니라 연속값으로 들어가서, 반쯤 쥐면 반쯤 뭉친다.

상태:
- `PROXIMITY` — 손이 화면에 있음. 유휴 드리프트가 빠지고 손이 회전을 잡음
- `CONTACT` — 주먹을 쥠. 코어가 당겨지고 부풂
- `RESIDUE` — 마지막 접촉점에 앵커. 링이 넓어지며 7초간 소산
- `ENERGY` — 손 이동 속도. 내부 접힘을 흔듦. 멈추면 감쇠
- 90초 무입력 → 흔적만 리셋 (`?exhibition`이면 45초)

왼손이 프레임에서 빠져도 크기는 마지막 값을 유지한다.

포인터는 폴백으로만 남는다. 중심 기준 반경 `0.80 / 0.42 / 0.20`.
예전 코드는 사각형 가장자리 거리로 재고 있었는데 `#field`가 뷰포트 전체라
감쇠 구간이 통째로 창 바깥이었다. `tprox`와 `tcontact`가 둘 다 1에 붙어서
PROXIMITY와 RESIDUE에 도달할 수 없었다 — 실질 1상태. 반경 방식으로 고쳤다.

## 형태 시드

`uSeed` 세 값이 관람객마다 다른 홀드를 만든다. 범위는 아카이브 17개가 정했다 —
로브 1~4개, 지배축 하나, 표면 특징 하나, 벽에 붙느라 납작한 뒤.
이미지는 안 쓴다. 형태는 여전히 전부 레이마칭에서 나온다.

| 시드 | 바뀌는 것 | 범위의 양 끝 |
|---|---|---|
| `x` | 로브 배치 (`axis` 상수를 흔든다) | CLOVER 4갈래 ↔ KNOT 두 덩어리 |
| `y` | 지배축. 좌표를 키우면 그 축으로 눌린다 | SPROUT처럼 길게 ↔ RAY처럼 넓게 |
| `z` | 표면 (`fold` 종착값 0.07~0.36) | VEIL처럼 매끈 ↔ CRUMPLE처럼 주름 |

`y=0`, `z` 중간이 예전 형태다. 기존 결과가 범위 안에 들어있고 거기서 갈라진다.
`z`를 0.4 넘기면 한 덩어리로 안 읽힌다.

시드는 필드가 비었다가 다시 찰 때만 굴린다. 뭉쳐 있는 동안에는 안 바꾼다 —
자기 홀드가 눈앞에서 딴 게 되면 안 된다.

`uSize`는 시드가 아니라 왼손이 정한다. 뭉쳤을 때 셸 반경 `2.10~3.75`.

모든 보간은 프레임레이트 독립(`1 - pow(base, dt)`).
평균 프레임타임 기준으로 렌더 스케일 0.55~1.0 자동 조절.

## 작업 방식

- 새로 쓰지 말고 있는 파일을 제자리에서 고친다. 최소 수정.
- 요청하지 않은 인터랙션을 추가하지 않는다.
- 값 조절로 되는 일에 새 기능을 만들지 않는다.
- 한국어. 건조하고 사실적으로. "흔적을 남긴다", "전이" 같은 표현 쓰지 않는다.

## 전시 구성 — 빈 벽

화면이 빈 클라이밍 벽이다. 관람객이 몸짓으로 자기 홀드를 만들어 벽에
하나씩 박고, 키보드로 방명록 한 줄을 남긴다. 벽이 채워지는 과정이 방명록이다.
받침대에 키보드 한 대. 누적은 그 화면 안에서만, localStorage.

CMF 네 축을 몸짓으로 정한다. 선택 UI 없이 전부 움직임에서 나온다:

| 축 | 몸짓 | 읽는 값 |
|---|---|---|
| 크기 | 다가오면 커지고 물러나면 작아짐 | `area` |
| 형태 | 손 궤적. 옆으로 쓸면 넓적, 위아래로 그으면 긺 | `cx, cy` 경로 |
| 재질 | 잘게 떨면 마찰, 느리고 크게 흐르면 실리콘, 일정한 리듬이면 결 | `energy` 시간 패턴 |
| 컬러 | 오래 붙들수록 진해짐 | 유지 시간 |

컬러 축은 자유 선택이 아니다. deck spec 네 색을 벗어나지 않는다 —
밀도 램프 `WHITE → GREEN → MID → BLACK` 위 어디까지 가느냐가 곧 컬러다.

**렌더 예산.** 100스텝 레이마칭은 풀스크린 하나로도 통합 GPU에서 스케일이
0.55까지 떨어진다. 벽에 여러 개를 라이브로 돌릴 수 없다. 확정된 홀드는 그
순간 한 번 구워서 정지 이미지로 벽에 붙이고, 레이마칭은 만드는 중인 하나만
돌린다. 벽이 100개가 되어도 비용이 안 늘어난다.
